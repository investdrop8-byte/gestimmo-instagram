# GEST'IMMO — visuels Instagram

Images publiques utilisées par Buffer pour programmer les posts du compte Instagram GEST'IMMO.

- `images/` : un fichier par visuel, nommé par date de publication.
- `planning.json` et `PLANNING.md` : dates, heures, légendes et stickers des stories.

## EDLYA

Le dossier `edlya/` contient les visuels du compte Instagram EDLYA (@edlya_app) : `edlya/images/`, `edlya/planning.json` et `edlya/PLANNING.md` (9 au 29 novembre 2026).
